Accessibility conformance statement

Target standard: WCAG 2.2 Level AA. This statement describes the ActaSeal console — the application an operator logs into. It does not describe this marketing site, which has not been through the same audit.

What was measured

11 console surfaces were audited: admin, agents, approvals, breaches, engagements, ledger, playground, policies, readiness, receipts, settings. Each was checked three ways. First, axe-core 4.10.2 was injected and run with the wcag2a, wcag2aa, wcag21aa and wcag22aa rule tags. Second, every focusable element was walked in DOM tab order and checked for a visible focus indicator when focused. Third, each focusable element's rendered box was measured against the 24×24 CSS pixel minimum target size, applying that criterion's own exception for inline text links. The login flow was then driven from the keyboard only.

Result

  • 2 automated violations across all 11 surfaces.
  • 0 elements without a visible focus indicator.
  • 4 elements below the minimum target size.
  • Login was completed using the keyboard alone, reaching the console without a pointer.
  • 7 of 11 surfaces had no finding of any kind: approvals, breaches, engagements, playground, policies, receipts, settings.

What was not measured

No assistive technology was used. No screen reader, no voice control, no switch device — the keyboard pass was scripted, not performed by a person who relies on it. Focus behaviour inside open drawers and modals was not checked, only each surface's base state. Live-region announcements were not verified. Reflow at narrow viewports was measured separately and is not part of this audit. This marketing site was not audited at all.

Automated tooling finds a minority of accessibility barriers. Passing it is a floor, not a conformance claim in the legal sense, and this page does not make one.

Evidence

Every number above is computed from the audit's own output, published here unedited. The page is generated from that file, so it cannot drift from it — a test in this repository fails if it does.
